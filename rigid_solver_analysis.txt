0-12. func_solve_mass

vec = dofs_state.force, out = dofs_state.acc_smooth 로 둬서 F = Ma 식을 다음 (0-13) func_solve_mass_entity 함수로 푼다.
이를 통해 acc_smooth 에다가 먼저 acceleration 을 계산해서 저장한다.

0-12-1. Inputs

- dofs_state: force
- rigid_global_info: mass_mat_L, mass_mat_D_inv

0-12-2. Outputs

- dofs_state: acc_smooth

0-13. func_solve_mass_entity

한 entity 에 해당하는 dof 의 mass matrix M 에 대해서 vec = M @ out 을 풀어서 out = M^{-1} @ vec 을 구한다.

M = L * D * L^T 로 이미 LDLT 분해되어 있다 (mass_mat_L 의 lower triangle + mass_mat_D_inv 의 diagonal).

이 함수의 grad 는 autodiff 에 의해서 관리되지 않는다. 나중에 Inverse Function Theorem (IFT) 로 manual 하게 계산한다.

0-13-1. Inputs

- vec
- rigid_global_info: mass_mat_L, mass_mat_D_inv

0-13-2. Outputs

- out

2-6. kernel_manual_compute_qacc_bw

func_compute_qacc 의 manual backward pass 이다. Inverse Function Theorem (IFT) 를 사용해서 acc.grad 로부터 
force.grad 와 mass_mat.grad 를 계산한다. 주의할 점은 func_compute_qacc 는 mass_mat_L, mass_mat_D_inv 를 사용
해서 acc 를 계산하지만 backward pass 에서는 이 LDLT 분해 행렬들에 대해서 grad 를 계산하지 않고 mass_mat.grad 를 바로
계산한다는 점이다. 하지만 이 분해 행렬들은 (현재로선) 여기에서밖에 사용되지 않으므로 괜찮다.
